Debit & Credit Analytics Dashboard

 📊 Project Overview
An interactive banking analytics dashboard developed using Tableau to analyze debit and credit transactions, identify financial trends, and present transaction insights through data visualization.

🎯 Project Objectives
- Analyze debit and credit transaction patterns.
- Understand financial transaction trends.
- Present key insights through interactive visualizations.
- Support data-driven financial analysis.

🛠️ Tools Used
- Tableau
- Data Visualization
- Financial Analytics

 📁 Project Files
- `Debit Credit Dashboard1 (1).twbx` – Tableau packaged workbook containing the dashboard.

🚀 How to Use
1. Download the `.twbx` file from this repository.
2. Open it using Tableau Desktop.
3. Explore the dashboard and available visualizations.
